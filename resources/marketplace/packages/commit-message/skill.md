# Commit message

When writing a commit message:

1. Focus on why the change exists, not a file-by-file inventory.
2. Match the repository's recent commit message style and tense.
3. Keep the subject concise (about one line); add a short body only when needed.
4. Use conventional verbs that match intent: add, fix, update, remove, refactor.
5. Do not mention tools, agents, or that the commit was AI-assisted.
6. Never invent changes that are not in the diff.
